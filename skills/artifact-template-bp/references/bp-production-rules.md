# 器官芯片 BP 模板规则

本文件只保存这套器官芯片 / 类器官商业化 BP 的模板与项目边界。通用的文字、绘图、版式和案例方法统一由 `presentation-craft` 提供，实际 PPT 读写、渲染和导出由 `presentations` 提供。

## 1. 适用范围

加载本文件的条件：

- 用户明确要求沿用旧版器官芯片 BP；
- 用户提供本项目旧 BP 作为视觉真源；
- 任务涉及本项目红灰 BP 的追加、替换或累计合并。

别人使用自己的行业和模板时，不需要本文件，只使用 `presentation-craft` 和 `presentations`。

## 2. 模板真源

以用户本轮指定的实际文件为准。本公开包不附带内置视觉真源；用户提供的授权模板优先。

从真实参考页复制或测量：

- 页面比例和背景；
- 左上角栏目标题的位置、字体、字号、颜色；
- 中央主标题的位置、字体、字号、字重和对齐；
- 红色分隔线、Logo、页码和底线；
- 正文、子标题、图注以及中英文混排字体。

浅灰背景、红灰配色或相似字体本身不能证明模板一致。不要用整页截图覆盖内容区来伪装沿用母版。

## 3. 本模板的制作边界

制作时必须区分：

- 团队既有科研成果；
- 可复用的芯片、模型、实验和数据基础；
- 正在集成的 MatElab、AI、自动化或高通量能力；
- 长期规划的平台和数据飞轮。

论文、合作单位、通用软件或参考 Logo 的能力不能直接写成本项目当前已经具备的稳定商业交付能力。外部关系没有合同、公开合作或部署证据时，使用中性的关系标签。

## 4. 本项目常见页面接口

这些是本模板中常见的页面类型，不是所有 BP 的通用默认值：

- 封面：标题和一句完整定位；
- 市场页：遵循旧 BP 页眉结构，使用过去 / 未来或趋势 / 约束关系；
- 痛点页：保持痛点判断的视觉优先级，数字紧邻解释；
- 解决方案页：若有 V1 / V2，作为独立方案清晰标注，不混合模块语义；
- 核心技术页：真实模型、芯片、实验、数字化系统和建设方向分开；
- 壁垒页：按当前母稿决定四区、单页或多页，不默删必须保留的成果资产；
- 团队页：按人物职责和项目贡献组织；
- 融资页：融资目标、股份或资金用途的分母和状态写清；
- 生态伙伴页：用户只要求展示关系时，使用简单 Logo 墙，不自行增加网络图和装饰解释。

具体金额、页数、标题、目录取舍、团队名单和合作名单属于当前项目决定，必须回到本轮母稿和决策记录核对，不能从这里复制到其他 BP。

## 5. 制作与交付

1. 先读 `presentation-craft` 的通用规则和案例，再读本文件与 `bp-production-checklist.md`。
2. 确认内容母稿、视觉真源、页面范围、保留页和版本关系。
3. 生成 `source_manifest`、`style_tokens`、`page_spec` 和 `asset_ledger`。
4. 在副本上制作，不覆盖公共原件；替代方案和累计稿分开保存。
5. 以 PPTX、PDF 和 PNG 检查同一已保存版本，核对字体、换行、裁切、页码、备注和对象编辑能力。
6. 交付状态使用“草稿”或“待审”；文件存在、渲染通过和 `final` 命名不等于业务批准。
