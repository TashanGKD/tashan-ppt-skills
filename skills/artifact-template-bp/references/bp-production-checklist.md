# BP 制作门禁清单

这份清单把 `bp-production-rules.md` 变成开始制作前、制作中和交付前的可执行门禁。四项预检材料不齐，不进入正式排版。

## Gate 0｜输入预检

建立 `source_manifest`，至少记录：

- 内容母稿：文件名、版本、路径、SHA-256、状态；
- 视觉真源：文件名、用于复制的页码 / 母版；
- 旧版素材源：文件名、页码或图号；
- MatElab / 外部来源：用途、来源状态；
- 本轮页范围：新增、替换、保留、删除；
- 旧版、替代版、累计版的关系；
- 未知、冲突和不应对外使用的内容。

禁止仅根据“最新版”“final”或文件修改时间合并不同版本。用户明确删除目录或更换母稿后，更新清单再继续。

## Gate 1｜视觉预检

建立 `style_tokens`，从实际视觉真源测量并记录：

- 页面尺寸和背景；
- 左上角栏目位置、字体、字号、颜色；
- 中央标题位置、字体、字号、对齐方式；
- 分隔线位置、颜色和线宽；
- Logo、页码、底线坐标；
- 正文、子标题、图注的字级和中英文字体；
- 可覆盖内容区和不可覆盖的母版元素。

至少保留一张参考页与新页的并排或叠加检查图，并记录文件路径和哈希。新页应从已确认参考页复制基底，再替换内容；只复用红灰颜色不能通过此门。

## Gate 2｜页面施工预检

每页建立 `page_spec`，至少包含：

| 字段 | 要求 |
|---|---|
| `question` | 读者看完要理解什么 |
| `conclusion` | 当前证据能支持的核心判断 |
| `subclaims` | 同一分类维度下的子论点 |
| `evidence` | 每个子论点旁边的真实素材、数据或关系示意 |
| `visual_center` | 投资人第一眼看到的对象 |
| `relationship_type` | 流程、比较、层级、因果、系统或案例 |
| `state` | 已有、可复用、集成中、规划 |
| `handoff` | 前页建立什么，本页交给后页什么 |

另建 `asset_ledger`，记录每张图片 / Logo / 图表的：

- 来源文件、页码或 URL；
- 事实证据 / 关系示意 / 类别标识 / 阅读引导；
- 裁切与比例限制；
- 支持的文字；
- 是否可编辑；
- 是否已在其他页面使用及获准的例外。

对用户要求“完整保留”的来源另建 `must_have_asset_ledger`，逐项记录原始页 / 图号、已放入页码或明确的拆页计划；只登记已放入素材不能证明没有遗漏。外部 Logo 和图片逐项记录来源 URL、访问日期、用户授权或公开关系状态及备注中的关系边界。

架构图另建 `node_edge_ledger`：每个节点是名词、状态和职责；每条箭头记录起点、终点、方向和语义（任务、控制、数据回流、模型更新、顺序或反馈）；涉及 AI 的页面增加 `ai_driver_coverage`，说明 AI 如何贯穿设计、执行辅助、分析和优化，而不是只出现在末端。

## Gate 3｜文案与视觉门禁

- 盖住图片和大数字后，正文仍能读懂核心判断；
- 数字旁边有对象、单位、时间、分母或比较意义，并写清它为什么与本页判断有关；外部公司名、缩写和专有术语首次出现时可被普通投资人理解；
- 痛点 / 判断的字级不小于辅助数字；
- 每页只有一个主要视觉中心；
- 没有把审计说明、制作说明和来源清单塞进正文；
- 没有默认三栏、四卡片、装饰性箭头或重复边框；
- AI 没有被误画成流程末端的单独步骤；
- 小闭环、干湿大闭环和真实数据回流都能被读者区分；
- 现有能力、建设中能力和规划能力的视觉强度不同；
- 用户要求完整保留的专利、采访、奖项、投入和网络没有被静默删掉；
- Logo 墙只使用中性关系标签，未把图片自动升级为已签约证据。

## Gate 4｜成品回归

渲染并检查同一版本的 PPTX、PDF 和 PNG：

1. 全套缩略图：节奏、重复构图、页眉和页码；
2. 单页实际显示尺寸：首要阅读顺序、文字可读性、图表意义；
3. 局部放大：字体替换、换行、裁切、遮挡、箭头和图例；
4. 页面插入 / 删除后的页码、目录和页脚，并与当前批准的页码 / 标题清单逐项对照；
5. 累计稿中冻结页面的文本、对象、层级和几何是否改变；必要时生成逐页结构 diff 或哈希对账；
6. 每页备注是否同时包含：页面问题、核心论证逻辑、原始素材文件及页 / 图号、外部来源、数据口径、证据限制、待核事项；缺一项则不能标记交付；
7. 图片重复、缺失来源、孤立 Logo、溢出和截断；
8. 对象是否真的可编辑，不把“可移动图片”写成“完全可编辑”。

只有完成实际导出和检查，才可标记“交付待审”。不能把程序通过、文件存在或对话框保存当成用户批准。

## 固定回归反例

以下情况一旦出现，返回 Gate 2 或 Gate 3：

1. 用一堆卡片和箭头代替系统关系；
2. 把孤立的 百分比、规模数字或范围数字放大成视觉中心，却没有解释对象和意义；
3. 左右未来 / 过去板块没有局部居中或不遵循真源骨架；
4. 痛点文字缩小到需要现场讲解；
5. 把 AI 放在流程末端的“反馈框”；
6. 增加没有必要的“团队体系”总览页；
7. 为了单页整洁删掉专利、采访、奖项或投入证据；
8. 把生态 Logo 做成复杂关系图，或把参考图片直接写成已合作证明。

## 文件化要求

四项门禁材料和最终检查记录必须保存为当前任务的实际文件，而不是只在聊天中口头确认。记录中写明路径、版本和哈希；任何一项缺失、空白或与当前 PPT 版本不一致，状态只能是“草稿 / 待补材料”。
