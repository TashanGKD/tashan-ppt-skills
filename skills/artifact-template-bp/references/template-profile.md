# Public template profile

This public package does not ship a visual master. When a user provides a template PPTX, record the actual file, page number, version, and intended role before editing.

Inspect at least:

- page size and background;
- top-left section label;
- main title position and typography;
- divider lines, footer, logo and folio;
- Chinese and English font hierarchy;
- safe content area and non-overridable elements.

A color resemblance is not enough to claim that a template was followed.
