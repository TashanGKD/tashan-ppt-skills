# 版式与信息密度

## 依据关系选择主体构图

| 内容关系 | 可选布局 | 选择依据 |
|---|---|---|
| 总体流程与重点环节 | 总览一侧/上方，局部证据另一侧/下方 | 读者先定位全局，再看本页强调的环节 |
| 多个同层理由 | 主结论下展开理由与对应证据，重要理由可占更大面积 | 同层逻辑清楚，证据可就近读取 |
| 流程中的问题 | 上方流程，下方按原因或环节定位约束 | 能看出问题发生的位置和原因 |
| 系统与闭环 | 按职责/层级布局，明确输入输出与回路 | 分层、箭头和边界反映系统关系 |
| 同维度比较 | 矩阵或并列图，共用维度、顺序和单位 | 读者可直接跨项比较 |
| 机制与观测 | 机制示意配相邻证据图 | 对象和现象有明确对应，图不替代因果证明 |
| 少数重要案例 | 每个案例给任务、方法和结果，突出差异 | 案例不是无标签的图片集合 |
| 团队与经验 | 按职责或相关能力分组，保留有依据的经历 | 让履历信息支撑团队能力判断 |

以上是可选方法，不是固定模板。三栏、卡片或表格在适用时可以用；不能为了凑相同块数拆散论证。

## 先排主次，再排细节

1. 标出主要阅读路径与一个视觉重点。
2. 给最重要的图、比较或系统关系足够面积，再安排辅助案例与来源。
3. 把子论点、证据及图注作为一个视觉组，保持稳定对齐与组间间距。
4. 用字级、字重、留白和少量线条建立层次，避免每句话都有独立彩框。
5. 完成真实文字后检查容量，不能用占位文案证明版式可用。

比较对象需要平等视觉权重时采用一致尺寸；主次本就不同则允许不对称。不同证据尺度要通过分层说明，不能靠同样大小的框暗示同口径。

## 高信息密度的处理顺序

适用于阅读型BP、总览和证据页。主结论突出；相关细节可以密集，但必须形成组和顺序。

空间不足时，依次考虑：去掉重复语句与无用装饰、精确裁切取用区域、调整分组和主次、将说明改成紧邻证据的短标签、采用表格或局部放大。最后才调整字号，仍须服从模板和实际可读性。固定页数时不自行增页或遗漏必需内容。

不要通过缩小整张旧页来制造“图很多”的效果；也不要为了“大字留白”删除对判断有用的事实。信息密度看有效信息与阅读负担，不看对象数量。

## 视觉关系检查

- 相邻表示相关，包含框表示归属，箭头表示一种明确关系；不要无意制造错误的关系。
- 颜色用于同类信息或状态，遵循模板；原科研图的颜色编码和图例必须保留。
- 连接器起止点、方向和标签匹配实际含义；避免线穿文字、箭头停在无关容器边缘。
- 科研小图要保留其解释所需结构。若需要展示多种轨迹、干预或对照，单个通用图标不足以说明。

## 三个观看尺度

- **全套缩略图：**检查节奏、重复构图、页眉一致性与整体层次。
- **单页实际显示尺寸：**检查先看到什么、读图顺序、主要文字和证据能否读懂。
- **局部放大：**检查图注、坐标、裁切、对象连接和细微遮挡。

局部放大清晰不能替代实际展示尺寸可读。对总览型页面，重点图的关键信息必须在整页中可辨认。
