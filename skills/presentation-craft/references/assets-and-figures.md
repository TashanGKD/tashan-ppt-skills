# 素材读取、裁切与绘图

## 先找证据，再定视觉形式

按本页论点读取相关原始文件。优先现有BP的实验/设备图、原论文图表、真实产品界面和可复核数据；不足时才为明确缺口检索补充材料。用户限制素材来源时遵循该限制。

可用一张轻量素材表，字段按需要简化：素材编号、来源文件/链接、页码或图号、取用区域、支持的论点、事实/示意身份、建议尺寸、裁切限制。

## 一张图的职责

| 职责 | 使用方式 | 常见错误 |
|---|---|---|
| 事实证据 | 真实实验图、实物、系统界面、测量结果 | 把示意图当成实物或把界面存在当成性能验证 |
| 关系解释 | 流程、机制、系统架构、对应关系 | 箭头暗示没有证据的因果，边框造成错误包含关系 |
| 类别识别 | 统一图标或小型示意提示器官、设备类别 | 用一个图标代替完整证据 |
| 阅读引导 | 视觉重点、方向、局部放大 | 装饰抢占证据面积或制造虚假的数据图形 |

## 拆图重组

- 从PPT或论文中提取原始图片/矢量对象，优先于截取整页缩略图。保留原件，裁切作为展示处理。
- 裁掉无关页眉与重复文字时，保留坐标、单位、标尺、图例、统计符号和必要实验条件。子图拆出后重新交代其所在实验。
- 需要指出局部时，用局部放大并保留整体定位；框线、标记与文字作为独立注释，不改变实验信号。
- 不拉伸实物、截图或Logo；不同图片通过显示区域、留白和图注统一，不强行改变内容比例。
- 同页多图按同一语义分组。每组由子论点统领，并紧邻一句说明它展示的现象或作用。
- 真实界面只截能说明功能的区域；缩小后重要文字不可读时，增加局部放大或可编辑短标签。不要用虚构界面替代实际功能证明。
- 同一素材可在不同问题中承担不同任务，但避免无意义重复。每次都需检查相关性和来源。

## 选哪种图

| 需要表达 | 优先方式 |
|---|---|
| 实物、组织、实验结果 | 真实照片、原始显微图、原论文图 |
| 同口径数值差异 | 原生条形/柱状/散点图，或保留足够信息的原图 |
| 同口径随时间变化 | 折线或区间图；不同研究的数字不拼成趋势 |
| 构成 | 基于真实分母的堆叠图或合适的比例图 |
| 同一批对象逐步筛选 | 可核对分母与阶段的漏斗图 |
| 模型、能力或状态比较 | 维度一致的表格/矩阵；不编主观评分 |
| 流程、机制、系统关系 | 明确节点与关系的示意图；需要可编辑时采用原生对象工作流 |
| 场景或解释性插画 | 依用户要求和当前工具规则使用图像搜索或绘图模型，标明示意身份 |

数据图由真实数据生成，记录单位、样本、条件、分母和必要误差。不能为了视觉完整编曲线、显著性、增长率或效果；抽象示意曲线不得伪装成实测。

## 新绘图先定义语义

写明：读者应理解什么、有哪些对象、对象间是什么关系、哪些细节决定理解、哪些标签必须保留。

- 区分样本流、数据流、控制指令、因果关系与阶段顺序；需要时用短标签或线型解释。
- 反馈箭头连接到真实调整的步骤，并说明返回的是分析结果、设计建议还是控制指令。
- 绘图模型用于解释性视觉。真实设备、实验读出、平台截图和测量数字保持原有来源。
- 请求可编辑的复杂科研图时，使用 `scientific-figure-pptx` 的对象与关系清单、科学微图和验证流程；图像中的文字与线条可按需要重新建立为真实对象。
- PNG/SVG放入PPT只是图片对象时，应明确内部不可逐项编辑；不将“可移动”称为“完全可编辑”。

绘图前考虑目标宽高比和最终显示尺寸。先检查参考/初稿的科学对象与连接，再投入细节和装饰。
